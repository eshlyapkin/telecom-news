Add source

        

          
          
          
          
          
          

            
          

        

        

        

          A sitemap source reads the list a site publishes for search
          engines — useful when an outlet has no feed. Point it at the site's
          news-sitemap.xml (or its root, and the usual paths are tried).
          Entries without a publication date are ignored: a plain archive listing cannot
          be told apart from fresh news.
        

      

      

        Toggle writes data/disabled_sources.json; Add / Delete write
        data/custom_sources.json and data/removed_sources.json.
        Built-in feeds are declared in code, so deleting one is a soft-delete overlay —
        adding the same id back restores it. Changes apply to this API
        process; restart run_pipeline / bot to pick them up elsewhere.

Discovery

        

          
          
          
          
          
        

      

      

      

        A scan looks for publishers two ways: a worldwide news search for the topics below,
        and the outbound links of articles already collected. Each site it finds is checked
        for an RSS/Atom feed and — when it publishes none — for a dated news sitemap, which
        collect can read just as well. Look for narrows that to
        one kind. Either way the result is scored with your AI rules: the
        share of recent headlines that pass the messaging gate. Nothing is added to the
        pipeline automatically: Add turns a proposal into a normal source,
        Dismiss silences that site for good.
        Schedule scripts/run_discovery.sh to keep watching continuously.
      

      

        
Search topics

        

          Generated from the messaging terms of your AI rules — discovery
          hunts for the same thing it later scores against, so widening the rules widens
          the hunt. Terms too generic to search on their own (sms,
          ss7) are left out, the rest are OR-ed in small groups, and each scan
          takes the next few groups so the whole rule set gets covered over several runs.
          Edit below only to search for something the rules do not express; Russian queries
          search the Russian-language press.
